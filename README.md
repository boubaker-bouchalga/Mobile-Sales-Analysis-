# Mobile Sales Analysis

## About the Project

Analysis of a mobile phone dataset using SQL and Power BI.

## Tools Used

* MySQL Workbench
* Microsoft Power BI
* SQL
* CSV Dataset

## SQL Analysis

* Total number of mobile phones and unique brands
* Minimum, maximum, and average prices
* Duplicate record checks
* Phone counts by brand
* Average price comparison between brands
* Top 10 most expensive phones
* Operating system distribution
* RAM and battery capacity analysis

## Power BI

A dashboard was created to visualize mobile phone data and present key information.

## Project Files

* `sql/`: SQL queries used in the analysis.
* `powerbi/`: Power BI dashboard file.
* `images/`: Dashboard screenshot.
